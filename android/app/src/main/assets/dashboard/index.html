📲 How it works

VyaparTrack runs 100% offline on your phone — no Node.js, no embedded server, nothing to crash.

  1. Customer sends you an order on WhatsApp (or you type one below).
  2. Tap 📤 Share on a saved order, or paste/type the order text above.
  3. The Poolside AI parser extracts customer / item / qty / cost / profit / total automatically.
  4. Hit 📤 Share on WhatsApp on any order to send a clean confirmation back to the customer.

Auto-tracking of incoming WhatsApp messages requires a server backend (the WhatsApp Cloud API or Baileys + Node.js). This app uses the simplest working setup: parse locally + share back.

⚙ Connect to server

VyaparTrack uses a small cloud server that runs WhatsApp + Poolside AI. The app's APK ships with a default server URL — just paste the API token from your server deploy to activate it.

No server yet? The app still works in offline mode — type or paste an order, the local parser handles it. You can deploy the server later (see DEPLOY.md) and connect for real WhatsApp tracking.
